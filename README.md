# Library Management System

A C# Console Application for managing books, library members, and book issue/return records using Entity Framework Core and SQL Server Express.

## Features

### Book Management
- Add new books.
- View all books.
- Search books by title or author.
- View a book by ID.
- Update book details.
- Update total and available copies.
- Delete books that have no issue history.

### Member Management
- Register new members.
- View all members.
- View a member by ID.
- Update member details.
- Delete members who have no issue history.

### Book Issue and Return
- Issue books to registered members.
- Check book availability before issuing.
- Store issue dates and due dates.
- Decrease available copies when issuing books.
- Record book returns.
- Increase available copies after returns.
- Prevent returning the same issue record twice.
- View issue records.

## Database Configuration

This project uses SQL Server Express.

**SQL Server instance:**
```text
(local)\SQLEXPRESS
```

**Database name:**
```text
LibraryManagementDb
```

Example `DatabaseConfiguration.cs`:

```csharp
namespace LibraryManagementSystem.Data
{
    public class DatabaseConfiguration
    {
        public string ConnectionString { get; set; } =
            "Server=(local)\\SQLEXPRESS;Database=LibraryManagementDb;Trusted_Connection=True;TrustServerCertificate=True;";
    }
}
```

Make sure the connection string matches the SQL Server instance installed on your computer.

## Prerequisites

- .NET 10 SDK
- SQL Server Express
- Visual Studio
- Entity Framework Core CLI tool

Check your .NET SDK version:

```powershell
dotnet --version
```

Install the EF Core CLI tool if it is not already installed:

```powershell
dotnet tool install --global dotnet-ef --version 10.0.14
```

## Setup and Run

### Step 1: Open the project folder

Open PowerShell in the folder containing `LibraryManagementSystem.csproj`.

### Step 2: Restore packages

```powershell
dotnet restore
```

### Step 3: Build the application

```powershell
dotnet build
```

### Step 4: Create the initial migration

Run this command only if the initial migration has not already been created:

```powershell
dotnet ef migrations add InitialCreate
```

### Step 5: Create or update the database

```powershell
dotnet ef database update
```

### Step 6: Run the application

```powershell
dotnet run
```

Ensure SQL Server Express is running before using the application.

## Main Menu

The main console menu provides these options:

```text
===== LIBRARY MANAGEMENT SYSTEM =====
1. Book Menu
2. Member Menu
3. Book Issue Menu
0. Exit
```

Choose an option by entering the corresponding number.

### Book Menu
Allows users to add, view, search, update, and delete books.

### Member Menu
Allows users to register, view, update, and delete members.

### Book Issue Menu
Allows users to issue books, view issue records, and record book returns.

## Application Flow

```text
User
 |
 v
Console Menus
 |
 v
Services
 |
 v
Repositories
 |
 v
LibraryDbContext
 |
 v
SQL Server Express
```

- **Menus:** Handle user input and display results.
- **Services:** Validate input and coordinate operations.
- **Repositories:** Perform database operations.
- **LibraryDbContext:** Connects EF Core entities to database tables.
- **SQL Server Express:** Stores the application data.
